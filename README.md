# Cargo Security Screening - Frontend (CSS & HTML)

**Cargo Security Screening** is a modern, fully responsive **front-end interface** for a cargo inspection system.  
It is designed with **clarity, usability, and aesthetics** in mind, inspired by government UI principles, while keeping your own design touch.

---

## 🚀 Project Overview

This project demonstrates a **clean login/dashboard UI** for a cargo security system.  
It includes:

- Split layout with **branding panel** and **login panel**
- Animated scan line effect
- Live clock display
- Feature highlights with icons
- Error message handling in forms
- Fully responsive design for desktop and mobile

This project focuses on **frontend development** using **HTML, CSS, and vanilla JS**.

---

## ✨ Features

- **Responsive Layout**: Works perfectly on desktop and mobile devices
- **Branding Panel**: Showcases system branding and highlights main features
- **Login Panel**: Secure access with username and password fields
- **Animated Scan Line**: Eye-catching animation for a tech-inspired look
- **Error Handling**: Inline error messages for invalid login attempts
- **Clock Display**: Real-time clock in the login panel
- **Reusable CSS Variables**: Easy theme and color customization

---

## 💻 Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, Variables, Animations
- **JavaScript** – Clock, interactive animations
- **SVG Icons** – Clean scalable icons for UI

---

## 🎨 Design Highlights

- Clean, minimal, and professional design inspired by government websites
- Gradients and soft shadows for depth
- Animated elements (scan line, status dots) for a modern tech feel
- Fully consistent color palette using CSS variables
- Features section highlights real-time detection, threat classification, and report generation
